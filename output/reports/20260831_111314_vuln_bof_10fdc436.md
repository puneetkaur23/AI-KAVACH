## 1. Vulnerability Summary

**Root Cause:** The function `process_name` copies up to 4095 bytes of data from `input` into a fixed-size 64-byte stack buffer `buf` using `strcpy` without performing length verification. When the input exceeds 63 bytes, `strcpy` writes past the end of `buf`, causing a stack-based buffer overflow.

**CWE Confirmed:** CWE-121 — Stack-based Buffer Overflow
**Exploitability Note:** Memory Write-Primitive / Buffer Overflow — high potential for arbitrary code execution.
